# Gerador Pix QR

Aplicação web local para gerar payloads Pix estáticos, QR Codes e placas personalizadas para impressão.

## Executar

```bash
npm install
npm run dev
```

## Verificar

```bash
npm test
npm run build
```

Os dados digitados são processados apenas no navegador. O projeto não possui backend, telemetria ou armazenamento de chaves Pix.
